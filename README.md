# Ibrahim Nasir - Portfolio Website

A modern, responsive portfolio website showcasing Mohammed Ibrahim Nasir's expertise across AI, Robotics, Full-Stack Development, and Technology Leadership.

## 🌟 Features

- **Dark/Light Mode**: Seamless theme switching with system preference detection
- **Modern Design**: Minimal, bold, and sleek aesthetic with smooth animations
- **Responsive Layout**: Optimized for all device sizes and screen resolutions
- **Interactive 3D Elements**: Animated sphere with rotating domain expertise indicators
- **Performance Optimized**: Built with Next.js 14 and Turbopack for fast loading
- **Type Safety**: Full TypeScript implementation with comprehensive type definitions
- **Accessibility**: WCAG-compliant design with keyboard navigation and screen reader support

## 🚀 Tech Stack

### Core Framework

- **Next.js 14** - React framework with App Router and Turbopack
- **TypeScript 5.0+** - Type-safe development environment
- **React 18** - Latest React features with concurrent rendering

### Styling & UI

- **Tailwind CSS v4** - Utility-first CSS framework with custom theme
- **Shadcn/ui** - Accessible component library with consistent design
- **next-themes** - Dark/light mode theme switching
- **CSS Custom Properties** - Dynamic theme variables

### Animation & Interaction

- **Framer Motion 10** - Advanced animations and page transitions
- **Three.js + React Three Fiber** - 3D graphics and interactive elements
- **GSAP** - High-performance timeline animations
- **Lottie React** - Lightweight animated graphics

### Development & Deployment

- **ESLint & Prettier** - Code quality and formatting
- **Husky & lint-staged** - Pre-commit hooks for quality assurance
- **Vercel** - Production deployment with global CDN
- **Vercel Analytics** - Performance monitoring and insights

## 🎨 Design Concept

The portfolio follows the **"Adaptability in Motion"** design philosophy:

- **Minimal & Bold**: Clean typography with strategic use of whitespace
- **Sleek Aesthetics**: Glass morphism effects and subtle gradients

- **Color Psychology**: Professional blue palette with accent colors for each domain

## 🔧 Development Setup

### Prerequisites

- Node.js 18.17+
- npm or yarn package manager
- Git for version control

### Installation

```bash
# Clone the repository
git clone [repository-url]
cd ibrahim-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

### Development Commands

```bash
npm run dev          # Start development server with hot reload
npm run build        # Create production build
npm run start        # Start production server
npm run lint         # Run ESLint code analysis
npm run type-check   # Run TypeScript type checking
```
