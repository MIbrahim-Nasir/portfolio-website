## ✅ **No Custom Domain Needed!**

Vercel automatically gives you a **free professional URL** when you deploy. No domain purchase required!

---

## 📝 **Simple 3-Step Deployment**

### **Step 1: Push Your Code to GitHub**

```bash
# Navigate to your project folder
cd "d:\Documents(D)\Ibrahim\Personal\Portfolio Website\ibrahim-portfolio"

# Initialize git (if not done already)
git init

# Add all files
git add .

# Commit your changes
git commit -m "Portfolio ready for deployment"

# Add your GitHub repository (create one first on github.com)
git remote add origin https://github.com/MIbrahim-Nasir/portfolio-website.git

# Push to GitHub
git push -u origin main
```

### **Step 2: Deploy on Vercel**

1. **Go to [vercel.com](https://vercel.com)**
2. **Click "Sign up" → "Continue with GitHub"**
3. **Click "New Project"**
4. **Find and import your `portfolio-website` repository**
5. **Click "Deploy"** ✨

**That's it!** Vercel will automatically:

- Build your project
- Deploy it to a global CDN
- Give you a free URL like: `https://portfolio-website-gamma-ten.vercel.app`

### **Step 3: Add Email Environment Variables**

1. **In your Vercel dashboard, go to your project**
2. **Click "Settings" → "Environment Variables"**
3. **Add these variables:**

   | Variable Name | Value                              |
   | ------------- | ---------------------------------- |
   | `EMAIL_USER`  | `mibrahimnasir.engineer@gmail.com` |
   | `EMAIL_PASS`  | `ykfjwppvoxrmcwhn`                 |

4. **Select all environments:** ✅ Production ✅ Preview ✅ Development
5. **Click "Save"**
6. **Go to "Deployments" → Click "..." → "Redeploy"**
